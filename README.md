# Dhanashree T. — Portfolio

A responsive, single-page developer portfolio built with HTML, CSS, and vanilla JavaScript. No build tools or package installation are required.

## Preview locally
1. Extract the ZIP (if downloaded as an archive).
2. Open `index.html` in a modern browser.

For a local server, run `python -m http.server 8000` in this folder and open `http://localhost:8000`.

## Before publishing
- Confirm the GitHub, LeetCode, HackerRank, and LinkedIn profile URLs in `index.html`.
- Add a source-code and/or live-demo URL for Password Strength Analyzer when available.
- The resume did not list project repository URLs, so no project demo or source-code button is shown.

## Deploy
This is a static website. You can publish the folder using GitHub Pages, Netlify, or Vercel static deployment.
